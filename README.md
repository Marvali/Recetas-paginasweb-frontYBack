# Práctica Arquitectura y Diseño de Sistemas Web – Parte 1  
📚 Curso 2025/2026 – Universidad de Alcalá  

## Descripción  
Este proyecto corresponde a la **Parte 1** de la práctica de la asignatura *Arquitectura y Diseño de Sistemas Web y C/S*.  
El objetivo es desarrollar una aplicación web sencilla tipo **red social para aprender a cocinar y compartir recetas**, utilizando tecnologías del lado cliente.  

## Tecnologías utilizadas  
- **HTML5** – estructura de las páginas  
- **CSS3** – estilos y diseño  
- **JavaScript** – comportamiento dinámico  
- **Visual Studio Code** con extensión *Live Server*  
- **Canva** – diseño de mapa de navegación  
- **Apache Tomcat** (para despliegue)  
- **Java JDK** (requisito para Tomcat)  

## Funcionalidades principales  
- Página de inicio de sesión y registro  
- Perfil de usuario  
- Línea temporal con publicaciones/recetas  
- Búsqueda de amigos  
- Mensajería entre usuarios  

## Tareas realizadas  
1. **Creación de páginas Web** (HTML + CSS + JS)  
2. **Validación de las páginas** con el validador del W3C  
3. **Despliegue en Apache Tomcat** para acceso desde navegador
